# Launchpad web

This is the Plan 4 Task 1 Next.js App Router boundary. It intentionally contains only a
diagnostic shell; product routes begin in Task 2 and later.

Use Node.js `24.16.0` and npm `12.0.1`.

```text
npm ci
npm run web-api-sync       # regenerate from ../backend/openapi/v1.json
npm run web-contracts-sync # regenerate after `cd ../contracts && forge build`
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
```

`src/api/generated.ts` is generated by openapi-typescript and `src/contracts/generated.ts` is
generated from the reviewed contract artifacts and deployment configuration. The corresponding
`*-diff` commands are byte-identical drift gates. Browser artifacts contain ABI fragments only;
they never contain bytecode or private configuration.
